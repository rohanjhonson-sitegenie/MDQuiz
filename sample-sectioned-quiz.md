# Web Development Fundamentals Quiz

This comprehensive quiz covers essential web development topics organized into logical sections. Each section focuses on a specific area of web development.

## Section: HTML Basics

This section covers fundamental HTML concepts including elements, attributes, and semantic markup.

### Q1
What does HTML stand for?

- [x] Hyper Text Markup Language
- [ ] High Tech Modern Language
- [ ] Home Tool Markup Language
- [ ] Hyperlink and Text Markup Language

### Q2
The `<div>` element is a semantic HTML element.

False: The <div> element is a generic container and is not semantic. Semantic elements like <article>, <section>, and <nav> provide meaning to the content structure

### Q3
What HTML attribute is used to provide alternative text for images?

Answer: alt

- [x] color

### Q5
What does the CSS property `display: flex` do?

- [ ] Makes the element flexible in size
- [x] Creates a flexible box layout
- [ ] Displays the element as flexible text
- [ ] Flexes the element's margins

### Q6
CSS Grid and Flexbox serve the same purpose and can be used interchangeably.

False: While both are layout systems, CSS Grid is designed for two-dimensional layouts, while Flexbox is designed for one-dimensional layouts

## Section: JavaScript Basics

This section covers JavaScript fundamentals including variables, functions, and basic programming concepts.

### Q7
What keyword is used to declare a constant variable in modern JavaScript?

Answer: const

### Q8
What will `console.log(2 + "2")` output?

- [ ] 4
- [x] "22"
- [ ] "4"
- [ ] Error

### Q9
In JavaScript, `null` and `undefined` are the same thing.

False: null is an intentional absence of value, while undefined means a variable has been declared but not assigned a value

## Section: Web Development Best Practices

This section covers modern web development practices including accessibility, performance, and security.

### Q10
What does ARIA stand for in web development?

- [ ] Automated Responsive Internet Applications
- [x] Accessible Rich Internet Applications
- [ ] Advanced Responsive Interface Architecture
- [ ] Adaptive Real-time Internet Access

### Q11
What HTTP status code indicates that a resource was successfully created?

Answer: 201

### Q12
It's a good practice to minify CSS and JavaScript files for production websites.

True: Minifying removes unnecessary characters (whitespace, comments) from files, reducing file size and improving page load times
