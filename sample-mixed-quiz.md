## Q2
JavaScript is a statically typed language.

False: JavaScript is a dynamically typed language, meaning variable types are determined at runtime

## Q7
The `===` operator checks for value equality only, not type equality.

False: The === operator (strict equality) checks for both value and type equality. The == operator only checks for value equality (with type coercion)
