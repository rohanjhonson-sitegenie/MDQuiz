## Q3

What does the 'this' keyword refer to in JavaScript?

Answer: The object that the function is called on, or the global object in non-strict mode

## Q4

JavaScript is a dynamically typed language.

True: JavaScript variables can hold different types of values and types are determined at runtime

## Q9

What is a closure in JavaScript?

Answer: A function that has access to variables in its outer (enclosing) scope even after the outer function has returned

## Q10

The '===' operator checks for both value and type equality.

True: === is the strict equality operator that compares both value and type
